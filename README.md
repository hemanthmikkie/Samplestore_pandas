# 🛒 Sample Superstore Data Analysis | Python & Pandas

## 📌 Project Overview

The **Sample Superstore Data Analysis** project is an end-to-end data analysis project developed using Python and Pandas. It focuses on analyzing retail sales data to understand business performance, product trends, customer segments, and regional sales patterns.

The project uses the Sample Superstore dataset to perform data exploration, data cleaning, preprocessing, and exploratory data analysis (EDA). The cleaned dataset is used to support further analysis and generate meaningful business insights.

## 🎯 Project Objectives

- Understand and explore retail sales data.
- Perform data cleaning and preprocessing.
- Identify and handle missing and duplicate values.
- Analyze sales and profit performance.
- Evaluate product category and sub-category performance.
- Understand customer segment and regional sales patterns.
- Generate meaningful insights to support business decisions.

## 📂 Dataset Description

**Dataset:** Sample Superstore

The dataset contains retail transaction information, including:

- Order ID and Order Date
- Ship Date and Ship Mode
- Customer ID and Customer Name
- Segment
- Country, State, City and Region
- Product Category and Sub-Category
- Product Name
- Sales, Quantity, Discount and Profit

## 🔍 Project Workflow

### 1. Data Loading
- Imported the original Sample Superstore CSV dataset.
- Loaded data into a Pandas DataFrame.
- Inspected the dataset structure.

### 2. Data Understanding
- Used `head()` and `tail()` to inspect records.
- Used `shape` to identify dataset dimensions.
- Used `info()` to understand column data types.
- Used `describe()` for statistical summaries.
- Checked missing values and duplicate records.

### 3. Data Cleaning & Preprocessing
- Checked and handled missing values.
- Identified duplicate records.
- Reviewed and corrected data types where required.
- Prepared the dataset for further analysis.
- Exported the cleaned data into a separate CSV file.

### 4. Exploratory Data Analysis (EDA)
- Analyzed overall sales and profit.
- Examined category-wise and sub-category-wise performance.
- Evaluated regional sales distribution.
- Explored customer segment performance.
- Investigated product-level sales trends.
- Compared sales, quantity, discount and profit.

### 5. Data Visualization
Used Python visualization libraries to explore patterns and communicate findings through graphical representations.

## ⚙️ Installation & Execution

### Step 1: Clone the Repository

```bash
git clone https://github.com/hemanthmikkie/Samplestore_pandas.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Samplestore_pandas
```

### Step 3: Install Required Libraries

```bash

```

### Step 4: Start Jupyter Notebook

```bash
jupyter notebook
```

### Step 5: Run the Project

Open `Samplestore.ipynb` and execute the notebook cells sequentially.
